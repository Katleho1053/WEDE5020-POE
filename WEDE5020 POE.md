This website presents information about Grantham Litchi Farm, including its products, services, farm history, product details, and contact information.

Folder Contents

The index.html file is the home page, while about.html provides information about the farm. The products.html and product-details.html files display the products and their details, services.html describes the available services, and contact.html contains the enquiry information. The styles.css file controls the website design, and the images folder contains the website photographs.

How to View the Website

3. The website will open in the default browser.

Search Engine Optimisation (SEO)

1. Definition and Purpose

Search Engine Optimisation means improving a website so that search engines can understand it and present it in relevant search results. Its main purpose is to help people find the website through organic, unpaid searches. Good SEO can therefore increase the number of visitors who are genuinely interested in the farm and its products.

2. SEO, User Experience, and Performance

The SEO helps improve the user experience by encouraging clear headings, useful content, simple navigation, mobile-friendly layouts, and descriptive links. It also promotes faster loading pages through optimised images, clean code, and efficient scripts. A website that is easy to understand, quick to open, and comfortable to use is more likely to keep visitors engaged.

3. Benefits

The SEO can improve a website’s visibility, credibility, traffic, and enquiries. It helps attract people who are already searching for litchis, farm visits, or similar services. SEO is also a cost-effective way to reach customers over time and does not require payment for every website visit, as paid advertising does.

4. Techniques Used

The website uses descriptive headings, relevant page titles, useful internal links, responsive CSS, meaningful image names, and alternative text for images. JavaScript is used only to add useful interactions and does not hide the main information from users or search engines. An example is shown below.

<h1>Grantham Litchi Farm</h1>
<img src="images/IMG-20260918-WA1029.jpg" alt="Litchi fruit at Grantham Litchi Farm">

5. HTML Meta Elements

HTML meta elements provide information to browsers and search engines about a web page. The charset element defines the text encoding, the viewport element helps the page scale correctly on mobile devices, and the description element gives a short summary of the page. Examples are shown below.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="description" content="Fresh litchis and farm products from Grantham Litchi Farm in Felixton.">
